## 🔥 The 10 Golden Rules (Never Break These)

```
1. NEVER store credit cards (use Stripe)
2. NEVER use plaintext passwords (hash with bcrypt)
3. NEVER mix tenant data (filter by tenant_id always)
4. NEVER send over HTTP (HTTPS only)
5. NEVER log passwords/tokens
6. NEVER trust user input (validate everything)
7. NEVER deploy one instance (use load balancing)
8. NEVER skip backups (test daily)
9. NEVER deploy without monitoring
10. NEVER ignore security warnings
```
